# SolidBOM synthetic STEP fixtures

These files are original, synthetic geometry created for the SolidBOM prototype. They contain no
customer data, no commercial-CAD output and no FreeCAD or other GPL-derived data.

| File | Content | Analytic expectation |
|---|---|---|
| `fixtures/three_boxes.step` | one product placed three times, each body 40 × 20 × 3 mm | one definition, three occurrences, 2400 mm³, translations 0/50/100 mm |
| `fixtures/open_surface.step` | one extruded rectangular surface, walls only | one definition, no enclosed volume |
| `fixtures/revisions_bc.step` | two products with the same part number, 3 mm and 6 mm thick | two definitions, 2400 mm³ and 4800 mm³ |
| `fixtures/flat_multi_body.step` | three solids in one product, no usable hierarchy | one definition, three bodies, 7200 mm³, review required |

`manifest.json` is authored independently from the files: the volumes come from the analytic box
dimensions, the transforms from the chosen translations, and the part numbers/revisions are the
test labels the workflow applies after import. Never replace an expectation with an imported
measurement.

## Regenerating

The files are written by an ignored engine test that uses SolidCraft's own STEP writer:

```sh
cargo test --profile ci -p solidcraft-engine --lib solidbom::tests::write_fixtures -- --ignored --nocapture
```

The test prints each file's SHA-256; update `manifest.json` if a fixture changes. The manifest is
checked by `crates/engine/src/solidbom/tests.rs`.
