  quantity and occurrence ids (and the customer part number/revision when the analysis carries
  one). It lists every calculation it knows about (in-session snapshots and reopened summaries,
  newest first), marks the current one, and shows an earlier loaded snapshot's own inputs and
  explanations with an explicit not-current label; summary-only rows say only the summary is
  available. A snapshot loaded for an older saved version is history, never current.
- **States, warnings and retry.** Analysis issues render as review-required lines (translated code
  and message) and are suppressed once a confirmed manual volume resolves that source finding;
  manual-volume provenance, a missing reason, `SaveFailed` with its exact message, the Save
  project/CAD save separation, the stale prior result with an explicit Recalculate path, and
  duplicate issue lines are all handled. Reference data arriving after a reopen reloads the
  material/rate choices while the part has no unapplied edits.
- **Controller corrections the acceptance needs.** A network failure no longer marks a configured
  service as missing, so `solidbom.retry` stays available and retries the identical failed request
  after the service recovers; a successful submission clears the flag. Display-only
  `browser.expand_all`/`browser.collapse_all` are allowed in a reviewed session because they do
