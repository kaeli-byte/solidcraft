The package brief's assignment gate asked for integrated prerequisites, locked grouping/selection/
provenance contracts, reserved shared files, an assigned owner/base and an explicit choice for
overlapping or incomplete associations. This increment satisfies them as follows:

- **Base and owner:** branch `agent/engineering-review-grouping-18deae34b2b7`, starting commit
  `71b9f91fb`; the worktree is recorded above. The shared edits are reserved in this record and
  listed in the JSON block; no other package's record, generated file or ledger row is edited.
- **Locked contract:** the version 1 engineering review and flat grouping contract, additive to API
  version 2, at `306eee219` in
  `docs/solidbom/contracts/v2/engineering-review-and-grouping.md`, registered in the contract
  registry with its portable types, producers, consumers and acceptance.
- **Provenance:** a grouping write names the exact `AnalysisKey` and the service accepts only a
  registered analysis whose manifest source hash equals the source hash the product revision's
  delivery package retained. An extractor or source change is a new analysis identity.
- **Overlapping or incomplete associations (the explicit choice):** a body may belong to at most one
  reviewed component of the same revision and exact analysis; all bodies of one component must
  belong to one definition, so several solids of a flattened definition may be confirmed as one
  component but different definitions are never merged; a body missing from the registered
  analysis is refused; an existing component is bound to one analysis and one revision; and for an
  input whose own extraction reported the flat guard, every registered body must be associated
  before the review reports no `unresolved_grouping` issue. No body is ever assumed to be its own
  component and no nested hierarchy is invented.
- **Confirmed decisions:** a predicted classification and its confidence never confirm; only the
  bulk confirmation action confirms a label or a recorded volume, records the authenticated
  reviewer identity and captures the label as training-example metadata. A manual completion cannot
  claim its own review. Unresolved associations, unassociated flat bodies, missing volumes and
  pending reviews are computed issues, not zeros.
