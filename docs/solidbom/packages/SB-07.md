# SB-07 — Review panel and persisted user workflow

## Objective

Deliver the three-section engineering/manufacturing/cost-explanation panel using the integrated controller and existing CAD tree/viewport.

## Requirements

Read [Prototype specification](../requirements/cost_calculator_handover/DESKTOP_PROTOTYPE_SPEC.md) and [application specification](../requirements/cost_calculator_handover/APP_SPECIFICATION.md). The application specification overrides compatible workbook formulas; proposals are not approved behavior. The original technical implementation plan is background evidence; package boundaries and current-code corrections in these briefs govern execution. Cover visible P01–P12/P14 workflow. Follow UI kit, theme, localization, commands and asset rules; preserve the existing viewport/camera path.

## Dependencies

Depends on: SB-06

Dependencies mean integrated predecessor work, including transitive predecessors, not a concurrent agent’s promise or an unreviewed artifact.

## Scope

- Render engineering review, manufacturing inputs and cost explanation with the existing UI container/panel system and theme tokens. Dispatch versioned application commands; perform no HTTP or costing in render functions.
- Show selected definition/occurrence, reviewed classification/sourcing/material, exact or manual volume and units, allowance/overhead/operation/setup inputs, quantity basis, line explanations and separate setup.
- Expose incomplete, stale, pending, dirty and failed-save states and explicit retry. Separate Save project from local CAD save and show historical results honestly.
- Label every result Draft prototype / Direct-cost subtotal and enumerate excluded categories; no activation or complete quotation action. Flat unresolved input remains review-required/uncosted; manual surface completion is explicit.
- Add native scenario coverage and real recorded UI evidence for the complete save/close/restart/reopen workflow. Do not replace source policy with hidden buttons.

## Interfaces

Consume the integrated SB-06 controller state and typed commands, plus its selection adapter. Any additional UI field must already map to the version 1 draft/result contracts or receive a coordinator-approved contract revision. Reuse the existing panel host/container, navigation and selection infrastructure; do not introduce a second viewport or direct document mutations.

## Ownership

Own `crates/ui-egui/src/solidbom/panel.rs`, area UI tests, `crates/ui-egui/tests/scenarios/solidbom-review.json` and a dedicated pending locale file. Reserve workspace/panel registration and shared module declarations through the coordinator. Capture screenshots/recordings under `.context/`; do not commit private media or generated files. Work in the dedicated user-created Conductor workspace assigned to this package. Do not rename its branch without an explicit request. Only one package owns a shared file at a time; ask the coordinator to reserve an integration edit before changing an unlisted shared file. SB-00 owns shared execution/bootstrap documents. Never modify generated files. Run `cargo xtask ci` before every commit; do not treat a package-specific check as a substitute. Do not claim unrun tests passed.

## Acceptance

- Select all three occurrences in tree and viewport; the same shared engineering record updates without placement changes.
- Review inputs, calculate through the real backend and show expected fixture explanations, 1.14/3.42 display values and separate 60 setup derived from unrounded amounts.
- Save, terminate the desktop process, restart and reopen by ID; recover source hash, mappings, reviewed values and the original saved calculation.
- Exercise 60-second stale/recalculate flow, missing inputs, manual surface volume, revision separation, flat guard and explicit failed-save retry.
- Run UI/scenario checks and inspect genuine screenshots/recording; report evidence for visible scope and policy behavior without claiming complete MVP readiness.

## Assignment gate

SB-06 and all its dependencies must be integrated. Assignment includes the exact controller/command contract references, integrated commit, verified service startup instructions and reserved UI registration files. An in-memory or mocked calculator cannot satisfy the persisted workflow gate.

## Handoff

Provide integrated commit, scenario/reproduction commands, native evidence paths, observed save/reopen results and per-criterion pass/fail notes. List unexecuted checks and deliver the runnable integrated workflow to SB-08 without a premature acceptance claim.
