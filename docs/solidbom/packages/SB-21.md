## Objective

Export detailed Excel and summary PDF for internal review using an explicit engineering/scenario baseline.

## Requirements

Read [APP_SPECIFICATION](../requirements/cost_calculator_handover/APP_SPECIFICATION.md), section 13, O11 and scenario 20. Exact layout and additional traceability fields are technical/presentation choices; customer quotation generation is excluded.

## Dependencies

Depends on: SB-20

Use integrated baseline selection, snapshot, incompleteness and stale-state contracts.

## Scope

Excel includes BOM, metadata, routings, feasibility, detailed costs and scenarios. PDF summarizes costs, annual prices/EBIT, tooling/setup charges and unresolved issues. Permit unfinished internal exports before activation, visibly labeled Draft / Incomplete with missing inputs and unresolved findings. Identify outdated costs. Export selected saved values without resolving newer master data silently.

## Interfaces

Lock export requests identifying project scope, baseline/scenario/calculation references and format; define a snapshot-resolved export model shared by both renderers. Specify selected version identifiers, issues and freshness labels in the technical contract. Typed export commands return a result/job without opening programmatic dialogs. Choose rendering dependencies and layouts before assignment.

## Ownership

Own proposed backend export-model/XLSX/PDF renderers, native export command/controller adapters and area tests. Reserve dependency/license additions, command registration and shared snapshot reads. Do not add business arithmetic to renderers or edit generated repository files. Own `execution/SB-21.md` only.

## Acceptance

- Both outputs reconcile to the selected snapshot, including annual totals and separate tooling/setup, even after current catalog values change.
- Draft exports identify missing inputs/findings and stale costs; no activation prerequisite or customer-facing label is introduced.
- Open/render produced XLSX/PDF and inspect readability, units, repeated rows, pagination and long labels. Use dynamic row counts, validate contents independently and record genuine export evidence plus actual checks.

## Assignment gate

Require integrated SB-20, locked export projection/metadata contract, approved dependency licensing, reserved shared files and chosen layouts. Resolve snapshot selection and partial-total presentation before assignment rather than substituting current data.

## Handoff

Record renderer versions, reproducible commands, public-safe output examples, reconciliation and visual inspection results. Supply SB-22 export acceptance evidence and limitations; retain private customer material locally.
