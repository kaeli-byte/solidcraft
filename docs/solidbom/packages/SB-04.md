# SB-04 — CAD extraction and stable source mappings

## Objective

Import the analytic STEP fixtures, extract exact definition measurements and map every reviewed occurrence to stable source-bound records without treating generated CAD IDs as persistent identity.

## Requirements

Read [Prototype specification](../requirements/cost_calculator_handover/DESKTOP_PROTOTYPE_SPEC.md) and [application specification](../requirements/cost_calculator_handover/APP_SPECIFICATION.md). The application specification overrides compatible workbook formulas; proposals are not approved behavior. The original technical implementation plan is background evidence; package boundaries and current-code corrections in these briefs govern execution. Own CAD behavior for P01–P03, P09–P11. Read repository command, crash-safety, file-format and test guidance before implementation; no kernel replacement or commercial-CAD reference extraction.

## Dependencies

Depends on: SB-01

Dependencies mean integrated predecessor work, including transitive predecessors, not a concurrent agent’s promise or an unreviewed artifact.

## Scope

- Create original STEP fixtures and independently authored manifests for three occurrences of a 40 × 20 × 3 mm box, an open surface, same-number revisions B/C and flattened input. Record provenance under repository rules.
- Build a source-key to runtime component/body/occurrence map and restore server UUID associations on verified reimport. Current `StepNode` lacks persistent occurrence entity IDs; explicitly define import receipt/mapping extensions required by the SB-01 contract.
- Preserve customer placements and hierarchy; report truncation/degradation and unresolved flat grouping. Never infer physical component identity from body count, labels or default BOM grouping.
- Measure definition geometry once through exact B-rep properties with closedness checks; quantity is separate. Open or partially unmeasurable components remain unavailable until manual completion.
- Resolve occurrence rows, definition-only tree picks and viewport body/face/edge picks. Use explicit body-frame/source mapping rather than parsing display names; a definition-only pick must not invent an occurrence.

## Interfaces

Implement the integrated version 1 analysis manifest/extraction and pick-resolution contracts. Persist source payload hash, import/extractor contract version and stable source keys; keep generated session IDs in a replaceable runtime map. Use `Document::body_frames_with_source` for explicit definition/occurrence resolution. Do not use selected-body `inspect.measure(items)` display-mesh volume as authoritative extraction; choose exact kernel/body properties and record units/source. Declare any import-boundary extension before touching shared files.

## Ownership

Own `crates/engine/src/solidbom/extract.rs`, package extraction tests in the area’s test module, and analytic fixture content under `tests/solidbom/`. Reserve shared `solidbom/mod.rs`, test aggregation, import-boundary files or kernel representation changes with the coordinator; never edit them concurrently with SB-05. Work in the dedicated user-created Conductor workspace assigned to this package. Do not rename its branch without an explicit request. Only one package owns a shared file at a time; ask the coordinator to reserve an integration edit before changing an unlisted shared file. SB-00 owns shared execution/bootstrap documents. Never modify generated files. Run `cargo xtask ci` before every commit; do not treat a package-specific check as a substitute. Do not claim unrun tests passed.

## Acceptance

- P01 source hash unchanged; independent definition/occurrence/transform manifest matches; degraded hierarchy is explicit.
- Six occurrence selections resolve correctly to one shared part/version; B/C remain separate. Reimport restores associations deterministically without reusing runtime IDs as identity.
- Exact one-part volume is 2400 ±2.4 mm³; count is three. Display quality changes do not change business extraction.
- Open and mixed closed/open inputs remain incomplete; flat input preserves geometry and requires grouping. Test missing/stale source keys and changed analysis version.
- Run focused engine tests; do not claim actual customer-file accuracy, automated recognition or P13 timing.

## Assignment gate

## Handoff

Provide integrated commit, fixture hashes/provenance, mapping algorithm/version, runtime-to-source adapter API, measurement evidence and unsupported/degraded cases. Give SB-06 stable contract references and import receipts, not screenshots as a substitute for mapping tests.
