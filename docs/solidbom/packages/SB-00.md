# SB-00 — Requirements and execution records

Depends on: none

## Objective

Make the full SolidBOM requirements and package execution history available to coding agents across user-created Conductor worktrees, with verifiable local reference data.

## Requirements

- Owner-approved delivery plan: full confirmed MVP, approved prototype first, one product package per worktree, Git-based tracking and independent review.
- Owner-selected storage: Markdown requirements and tracking in Git; CAD/workbooks/PDFs/CSV/reference JSON copied locally.
- Preserve confirmed/proposed/historical distinctions and the authoritative application specification's precedence over workbook behavior.

## Dependencies

No product prerequisite. Baseline: `871014f955a76fd308ce156e68c93e6372906005`. This is the bootstrap package; it needs no product contract lock.

## Scope

Import the 17 original Markdown documents unchanged; retain the 53 local references beside them. Create the manifest, active plan, coverage map, package briefs, contract registry, coordinator ledger, per-package execution records and agent handoff instructions. Configure local-reference copying and provide a hash/state validation tool. Hydrate the main checkout's ignored references while preserving existing local settings.

No CAD, business service, costing engine or product UI is implemented here. Do not publish, merge or create product workspaces as a side effect. SB-01 cannot start until this package is integrated into its assigned base.

## Interfaces

- `reference-manifest.json`: schema version 1, destination, and file entries with relative path, storage (`git`/`local`), byte size and SHA-256.
- `package-index.json`: schema version 1, review baseline, package IDs/titles/stages and dependencies.
- Execution Markdown starts with a JSON record following [the record format](../execution/README.md). Agents own their records; the coordinator owns the ledger and state decisions.
- `python3 scripts/solidbom_workspace.py check [--require-references]`: read-only validation; exit nonzero on missing/changed required sources, broken links or invalid tracking gates.
- `status`: dependency eligibility only, not assignment approval. `hydrate --source PATH [--workspace PATH]`: preflight all hashes and conflicts, then copy only ignored local references.
- `source-ci`: temporarily detach manifest-verified ignored references, run the unchanged `cargo xtask ci`, then restore them; preserve recovery backups on conflicts.

## Ownership

Own `docs/solidbom/`, `scripts/solidbom_workspace.py`, `scripts/test_solidbom_workspace.py`, the SolidBOM pointer in AGENTS.md, and scoped `.gitignore`/`.worktreeinclude` entries. Reserve these edits in EXECUTION.md. Documentation authoring and review may be delegated inside this bootstrap package; that does not assign product packages to this worktree.

The approved local setup may seed ignored references in Conductor's main checkout, add exact reference ignore patterns to shared local Git excludes, and preserve/extend local Files-to-copy settings. Do not edit that checkout's tracked application code or branch.

## Acceptance

- All 70 imported files match their hashes; 17 Markdown files remain trackable and 53 references remain ignored.
- All imported and active relative Markdown links resolve when references are hydrated. A fresh clone check permits explicitly inventoried missing local references.
- All 24 package briefs/records exist, dependencies are acyclic and consistent, and no unimplemented package is represented as integrated or verified.
- The coverage map includes P01–P14 and A01–A20 with authority qualifications and owning packages.
- Hydration is repeatable and rejects a missing/changed source or differing destination before copying. It does not overwrite user changes.
- Invalid readiness/integration records fail validation. Required repository gates and independent review results are recorded honestly.

## Assignment gate

Assigned to the existing coordinator workspace for bootstrap. Subsequent package assignment requires SB-00's actual reviewed/integrated commit, the locked package interfaces and a user-created Conductor workspace. A documentation draft is not proof of implementation readiness.

## Handoff

Update [the SB-00 execution record](../execution/SB-00.md) with exact checks, implementation/review/integration commits when they exist, local reference provisioning and the next action. Leave overall milestones Pending. The next candidate is SB-01; do not begin it in this package's worktree.
