# SB-18 — Commercial scenarios

Status: in progress; the commercial-scenarios contract is locked (version 1, additive to API
version 2) and the pure `solidbom-commercial-scenarios/1` calculator, the append-only project
commercial settings write, the append-only named scenario versions and the read-only comparison are
implemented on branch `agent/commercial-scenarios-9b231710037e`. The desktop comparison surface and
its native evidence are pending the still-open SB-10/SB-15/SB-16/SB-17 desktop wiring.

## Objective

Compare named commercial alternatives with clear base prices, recurring EBIT and separately displayed tooling/setup.

## Requirements

Read [APP_SPECIFICATION](../requirements/cost_calculator_handover/APP_SPECIFICATION.md), section 12, O01/O02 and scenarios 14–17 and 19. Scenario comparison metadata marked Proposal requires an explicit technical contract.

## Dependencies

Depends on: SB-17

Use integrated manufacturing baseline, configured recurring categories and tooling recovery interfaces.

## Scope

Keep suggested and manual base prices visible together. Compute first-year suggested price C/(1−t) and manual-price recurring EBIT from configured operating cost C. Project EBIT target and volume method are shared across scenarios. Apply annual productivity to base prices from each product's first production year, with scenario choice for tooling productivity and separate/amortized mode. Exclude tooling/setup from recurring EBIT; show charges and yearly revenue separately. No customer-facing quotations or lifetime-target solver.

## Interfaces

Lock named scenario records, baseline references, manual prices and annual price/EBIT/revenue outputs. Expose typed create/edit/compare operations with immutable saved versions and explicit missing/stale states. Consume SB-17 recovery functions; do not duplicate its investment logic or mutate project forecasts from scenarios.

## Ownership

Own proposed commercial calculator, scenario persistence/controller and comparison UI modules with area tests. Reserve shared snapshot/baseline types, migrations, command registration and tooling interface changes. Own `execution/SB-18.md` only.

## Acceptance

- Base price 100 with 3% annual productivity gives 100/97/94.09, while manufacturing cost stays fixed absent other adopted changes.
- With tooling contribution 2, first-year total is 102; year two is 99 when exempt and 98.94 when productivity applies to both.
- Blank manual price has no valid manual-price EBIT; a positive price shows amount and rate distinctly. Target below 100% uses first-year C/(1−t). Scenario changes cannot override volume policy/EBIT target or mix baselines without labeling. Capture comparison UI evidence.

## Assignment gate

Require integrated SB-17, locked annual timing/baseline/scenario contracts, reserved files and an assigned base commit. Establish tooling-switch interaction acceptance numerically before testing; do not invent a target from the prototype delay test.

## Handoff

Record formula/contract versions, scenarios and independent results, stale-baseline behavior, actual checks and evidence for SB-20/SB-21. Report missing-price outputs without suppressing the suggested price.
